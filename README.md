# ProtBuild

ProtBuild is a research project focused on learning the language of protein sequences and developing models that can understand and describe their properties and functions.

The project aims to train a protein language model to learn meaningful representations of amino-acid sequences, alongside a descriptor model that learns to translate protein representations and properties into human-readable descriptions.

The long-term goal is to build a system that can connect **protein sequences, their learned representations, and natural-language descriptions**, providing a foundation for protein understanding and, eventually, protein design.
