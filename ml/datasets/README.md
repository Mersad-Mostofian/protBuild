# Datasets

## 1. UniProtKB/Swiss-Prot

**Description:** Reviewed protein sequences from UniProtKB/Swiss-Prot, including basic protein metadata such as accession, protein name, organism, gene, and amino acid sequence.

**Source:** UniProt

**Download:**

[UniProtKB/Swiss-Prot FTP](https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/complete/)

**Main FASTA file:**

```text
uniprot_sprot.fasta.gz
```

**Download with `wget`:**

```bash
wget https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/complete/uniprot_sprot.fasta.gz
```

Extract:

```bash
gunzip uniprot_sprot.fasta.gz
```

## 2. UniRef90

**Description:** A non-redundant protein sequence dataset generated by clustering UniProt sequences at 90% sequence identity. UniRef90 reduces redundancy while preserving a broad representation of protein sequence diversity, making it useful for large-scale protein language model training.

**Source:** UniProt

**Download:**

[UniRef90 FTP](https://ftp.uniprot.org/pub/databases/uniprot/current_release/uniref/)

**Main FASTA files:**

```text
uniref90.fasta.gz
```

**Example FASTA entry:**

```text
>UniRef90_A0ACG4HM60 LacI family DNA-binding transcriptional regulator n=1 Tax=Nocardia arseniciresistens TaxID=3392119 RepID=A0ACG4HM60_9NOCA
```

**Download with `wget`:**

```bash
wget https://ftp.uniprot.org/pub/databases/uniprot/current_release/uniref/uniref90.fasta.gz
```

Extract:

```bash
gunzip uniref90.fasta.gz
```

## 3. UniParc

**Description:** The UniProt Archive (UniParc) is a comprehensive, non-redundant archive of protein sequences collected from multiple sequence databases. It provides broad protein sequence coverage and is useful for large-scale protein sequence modeling.

**Source:** UniProt

**Download:**

[UniParc Active FASTA FTP](https://ftp.ebi.ac.uk/pub/databases/uniprot/current_release/uniparc/fasta/active/)

**Dataset used in ProtBuild:**

Only a subset of the available UniParc Active FASTA parts was downloaded and used for this project. The complete UniParc dataset was **not** downloaded.

The dataset is distributed across multiple compressed FASTA parts.

**Example FASTA entry:**

```text
>UPI00000000D1 status=active
```

**Download individual parts with `wget`:**

```bash
wget https://ftp.ebi.ac.uk/pub/databases/uniprot/current_release/uniparc/fasta/active/<part>.gz
```

**Extract:**

```bash
gunzip <part>.gz
```
